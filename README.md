# Beginner C Programs 💻

A collection of small C programs I'm building while learning C as part of my Computer Science studies.

The programs in this repository are focused on practicing programming fundamentals, problem-solving, and gradually exploring more advanced concepts.

## Topics

- Variables and data types
- User input and output
- Conditions
- Loops
- Functions
- Basic algorithms

## Programs

### Temperature Converter
Converts a temperature from Celsius to Fahrenheit using user input.

### Even or Odd
Checks if a number is Even or Odd. Simple use of the If-Statement in C. 

### Rock, Paper, Scissors
Simulates a rock, paper and scissors game using simple Conditional Statements and Logic Gates. 

### Calculator
Does simple arithmetic calculations with user inputs. 

### Smart Garden Menu
Console-Menu that can manage devices and user can change devices and interacts with the menu.

### Random Temperature
This C program generates random daily temperatures for a week and stores them in an array. It then calculates and displays the average temperature for the entire seven-day period.

### Using-Arrays
This Directory contains programs where you can see the use case of strings & arrays in C and how  outputs of arrays are written.

> This repository will grow as I continue learning C.
